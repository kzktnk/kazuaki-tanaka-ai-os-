# Environment Management Guide

**Version:** v1.0  
**Status:** Active  
**Owner:** Kazuaki Tanaka  
**Origin:** 大規模基幹系更改案件の開発環境／試験環境ガイドライン（2003/12）を一般化。クライアント名・ベンダー名・固有情報なし。

---

## Purpose

発注側が提供する**開発環境・試験環境**の運用方針、サービス定義、利用・管理原則を定義する標準です。

品質向上と維持管理負担低減のため、本番環境との**同一性**と**三者責任分界**を明確にします。

`standards/release-management-guide.md` の PT/RT リリースと接続します。

---

## When to Use

- プロジェクトキックオフ時の環境利用ルール合意
- 総合試験（PT）・総合運転試験（RT）環境の設計
- サービス開始後の開発環境（変更開発）運用
- ベンダー/on-site 運用委託との環境 SLA

---

## Environment Landscape

| 環境 | 用途 |
|------|------|
| **本番** | エンドユーザへのサービス提供・実運用 |
| **試験** | 発注側: 総合運転試験 / ベンダー: 総合試験・障害検証 |
| **研修** | ユーザ研修 |
| **開発** | Go-live 後の仕様変更・追加開発 |

本ガイドラインの**開発環境編**は Go-live 後の開発環境、**試験環境編**は PT/RT を主対象とする（プロジェクト期間中の共有試験も含む）。

---

## Parity with Production

開発/試験環境は以下を**本番と同一**とする（不可の場合は差分影響を文書化）：

| 項目 | 内容 |
|------|------|
| OS | バージョン、適用パッチ |
| AP/MW | バージョン、リビジョン、パッチ |
| ツール | コンパイラ等のバージョン |

---

## Roles

| 関係者 | 開発環境 | 試験環境 |
|--------|---------|---------|
| **発注側** | HW/SW 調達、統括管理 | 同左 |
| **運用委託** | 環境変更・日常管理 | 同左 |
| **開発ベンダー / AP維持** | 環境利用・AP 開発 | 環境利用・試験実施 |

開発/AP維持が運用委託に代わって開発環境を管理する場合もある（責任は文書化）。

## Service Catalog

### 開発環境（3サービス）

| サービス | 内容 |
|---------|------|
| **環境提供** | サーバ、NW、ラック、OS、AP/MW、ツールの貸出 |
| **運用情報提供** | システムアカウント、NW 情報 |
| **バックアップ/リカバリ** | OS/環境定義（標準）、その他（依頼ベース） |

**利用工程:** 製造（M）〜結合（SI）  
**管理方針:** 最低限の管理のみ（開発負担軽減）

### 試験環境（4サービス）

| サービス | 内容 |
|---------|------|
| **環境提供** | 開発環境と同様 |
| **運用情報提供** | システム/AP ユーザ、DB、NW 情報 |
| **AP提供** | ライブラリ/リリース管理、業務日付（タイム管理） |
| **バックアップ/リカバリ** | OS/環境定義（不定期）、重要データ（定期/不定期） |

**構成:** PT 環境 + RT 環境  
**基本方針:** 発注側が効率よく試験できる環境運用

## Security Guidelines

| 領域 | 要点 |
|------|------|
| **ユーザ認証** | パスワード、システム/AP ユーザ区分、権限によるサービス範囲限定 |
| **システム環境** | 施設管理、セキュリティパッチ、ウイルス対策 |
| **データ** | 授受・保管方法の規定、改ざん防止 |
| **外部接続** | 相手先確認、接続条件の登録・変更管理 |

組織のセキュリティガイドラインに準拠する。

---

## Management Principles

### 環境提供（共通）

1. 発注側: 機器調達、保守連絡先の明確化  
2. 運用委託: 運用、環境情報ドキュメント、作業証跡、変更時更新  
3. 障害時: 発注側へ状況説明 → 保守交換依頼 → 動作確認  

### 試験環境固有

- **ライブラリ/リリース:** 業務 AP の版管理（`release-management-guide.md`）  
- **タイム管理:** 業務日付・カレンダーの試験用変更  

---

## Usage Rules (Summary)

| ルール | 内容 |
|--------|------|
| 共同利用 | ルールに従い共同で環境を利用 |
| 変更記録 | 環境変更はドキュメント・証跡を残す |
| 本番差分 | 差分がある場合は試験結果への影響を評価 |
| 引継 | Go-live 時、本番との差分を運用引継に記載（`operations-handover-guide.md`） |

## Review Checklist

- [ ] 本番との OS/MW/ツール同一性（または差分と影響）が文書化されているか  
- [ ] PT/RT の役割分担がリリース規約と一致しているか  
- [ ] セキュリティ（認証・外部接続）が組織基準を満たすか  
- [ ] バックアップ/リカバリの範囲が合意されているか  
- [ ] 運用委託・ベンダー・ア維持の責任分界が明確か
