# Pattern: A Change Catalogue Is Not the Plan

**Status:** Active  
**Origin:** Anonymized OCM method catalogue and the local screen of which tools were field-ready (Program Line AM). Tool text, survey items, personality instruments, culture models, and client proposals are **not** stored here.

## Pattern statement

> **方法論のカタログは、変革の計画ではない。現場に出すのは、効果があり、案件をまたいで使え、すぐ使え、読んだ人が同じように使える道具だけ。それ以外は登録しない。**

カタログは仕事の抜けを探す地図である。七つを順に実施する手順ではない。

| 仕事 | 問うこと |
|------|----------|
| リーダーとガバナンス | リーダーが意義を説明し、成果の責任を持っているか |
| 変革の進め方 | 計画が一本で、業務と組織の到達に繋がっているか |
| 組織の設計 | 役割と決裁が、新しい仕事に合うか |
| ステークホルダーとコミュニケーション | 誰が動き、何をいつ聞くか |
| 文化 | 公式のプロセスを殺す、非公式のルールは何か |
| 技能 | 新しい仕事をできるか。研修に出たか、ではない |
| 便益 | 稼働のあと、便益が使われているか |

欠けている仕事を埋める。七つのツール箱を全部開かない。

## What leaves the catalogue

道具は次の四つを通ったものだけ残す。

- 効果がある  
- この案件の外でも使える  
- すぐ使える  
- 読んだ人が、同じように使える  

チーム役割の診断、リーダーシップ様式、対人スタイル、文化モデルの調査票は、この四つを通っても OS には置かない。顧客がすでに使っている場合だけ、その現場の外に出さない。

## Investment case is not the change brief

投資の可否を説明する文書は、費用と便益で組織がお金を出すかを答える。現場への説明は、この部門とこの人に何がいつ変わり、なぜかを、リーダーが自分の言葉で言えることである。投資説明を配って、説明したことにしない。

役割と業務がどう変わるかは、仕事をしている人と確認してから研修資料にする。チェンジマネジメントは To-Be を発明しない。

## Signals

- 方法論の章立てを、そのまま WBS にしている  
- ツール一覧の消化が、変革の進捗になっている  
- 診断票の得点が、計画の中身になっている  
- 投資説明だけが現場に配られている  
- 研修資料が、役割への影響の確認より先にある  

## Tests

- カタログの七つのうち、この案件で欠けている仕事を一つ言えるか  
- 残した道具が、四つの試験を通っているか  
- リーダーが、投資説明を見ずに、この人への変化を言えるか
