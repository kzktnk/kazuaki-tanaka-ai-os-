## 1. なぜ EBIDTA ツリーを SCN の背骨にするか

### 1.1 課題（従来 SCN の弱点）

| 弱点 | 具体 |
|------|------|
| 施策との接続が弱い | Enabler 層に Technology が並び、**誰のどんな行動→EBITDA** が見えない |
| 会話のフレームが分裂 | 森崎様・McK は EBITDA/Value Driver、長嶋様報告は SCN/KOPT、現場は KPI/アプリ |
| DPP 再演リスク | ツールマッピングで終わり、利用率 KPI 化（G7） |

### 1.2 McKinsey 6/29 の合意（SCN 再設計の入力）

- EBITDA 分解は**分析ではなく**「ツール→仕事のやり方→判断・行動→成果」の**一連の流れ**として設計する（6/29 メモ p.1）
- **発電所長＝EBITDA 成果責任主体**。DX/デジタルは手段（1C）
- **デジタル＋非デジタルの包括目標**を EBITDA ツリー 1 本に載せる（1B）
- モデル発電所は **1 拠点×1–2 プロセス×2–3 年ストレッチ目標**（2B, 3A）
- DPP 失敗＝横展開前成果確認不足・業務統制未連携・アプリ先行（2B）— **BPR として横展開可能に設計**

### 1.3 SCN への当てはめ方（v1.2：Value Creation Tree）

**6層構造**（EBITDA ツリー単体ではなく **Value Creation Tree** として提示）：

```
EBITDA（Outcome）
  ↓
Value Driver（遅行/先行 KPI・有報費目の因数分解）
  ↓
Management Decision（誰が何を判断するか）
  ↓
Business Process（業務プロセス）
  ↓
Capability（～できる能力）
  ↓
Digital / AI（Enabler・手段）
```

| SCN 層 | Value Creation Tree での役割 |
|--------|------------------------------|
| **Value** | 頂点＝**発電 EBITDA 最大化**（Outcome KPI）。有報費目は**結果**として接続 |
| **Decision**（拡張） | **発電所長・本社の経営判断**（運転計画見直し、修繕優先、AI 採否等）。鈴木様コメント「判断」の明示レイヤ |
| **Capability** | **Business / Enterprise** に分類した「～できる能力」。Monitor KPI＋**Decision KPI** |
| **Enabler (KOPT)** | **BPR を先行**（DPP 教訓）。Technology / AI は手段列 |

**長嶋様→森崎様報告:** 施策→**BPR**→Capability→**判断**→Value Driver→EBITDA の連鎖で説明する。

### 1.4 有報整合の設計原則（2026-08-13 レビュー反映）

有価証券報告書（第10期・2025年3月期、`securities_report2506.pdf`）との突合レビューに基づき、**Value と費用枝の会計基準・範囲を統一**する。

| 設計判断 | 内容 |
|---------|------|
| **採用基準** | **個別財務諸表（JGAAP・親会社単体）** に統一 |
| **Value-1** | **電気事業営業利益 124,483 百万円**（有報 P.140–142 個別・電気事業） |
| **非採用** | 連結 IFRS セグメント利益 124,324 百万円（P.85）— 費用枝（個別）と縦足しが成立しないため |
| **EBITDA 加算 D&A** | **116,753 百万円**（個別・汽力発電費内減価償却費）。連結セグメント D&A 199,593 百万円（P.85）とは別物 |
| **スコープ** | **電気事業（汽力発電費）のみ**。ガス供給事業（収益 421,320／費用 415,958 百万円）は本ツリー対象外 |
| **網羅性** | 主要変動費・固定費の**抜粋**。一般管理費・接続供給託送料・事業税（計 185,496 百万円）は未掲載 |
| **出典ページ** | 有報**フッター印字**ページ番号（P.140–142、P.85）を使用。PDF 内部ページ順とは異なる |

**符号ルール:** 収益項目（＋）と費用項目（－）をツリー上で明示。Cap-A には収益（他社販売電力料等）と費用（他社購入電力料）が混在するため、P/L 種別を区別する。

**Capability 紐づけ:** 燃料費・人件費等は**複数 Capability に重複紐づけ**可（1 費目→複数能力の設計意図）。排他分割ではない。

**担当者名:** 手川 PM はヒアリング資料で確認済。AMP PJ オーナー（旧表記「高橋 PJ」）は体制図で要最新確認。

### 1.5 Partner レビュー反映（2026-08-13・v2 SCN）

**評価（92点）:** EBITDA→Capability→施策ストーリー、有報対応、C-0 主経路、G7 連鎖は高評価。

**残り 8 点＝Decision（判断）レイヤと Value Driver の明示：**

| 指摘 | 対応 |
|------|------|
| ① 費目と Capability の直結 | **Value Driver 層**を追加（例：燃料費→熱効率→運転最適化→C-A2） |
| ② Capability 粒度混在 | **Business Capability**（運転/保全最適化）と **Enterprise Capability**（PDCA/標準化/権限）に分類 |
| ③ 所長の判断が見えない | **Decision 層**＋ Decision KPI / Owner 列を Capability 表に追加 |
| P2 ねらい | Value → **Decision** → Capability → Enabler |
| P7 Enabler | 施策より **BPR 先行**（モデルプラント AI → BPR → Cap → EBITDA） |
| G7 | **判断 → 行動 → KPI → EBITDA 枝** |

**目標:** SCN から **JERA Operating Model 設計図**へ昇格。

## 2. EBITDA ツリー構造（McK 6/29 p.7 ベース）

```
発電EBITDA（円）                          ← SCN Value-1（Outcome）
└─ 粗利益
    ├─ 送電電力量（MWh）                  ← 収益ドライバー Cap-A
    │     × スプレッド（円/MWh）
    ├─ O&M 固定費（円）                   ← コストドライバー Cap-B
    │     ├─ メンテナンス費
    │     │     └─ 単価 × 数量
    │     ├─ オペレーション費
    │     │     └─ 可変費・起動費・効率
    │     └─ 内部/外部コスト
    ├─ 計画停止（MWh）                    ← Cap-C1（McK 3A-①）
    └─ 計画外停止（MWh）                  ← Cap-C2/C3（McK 3A-②③）
```

**管理 KPI（McK p.9 例）:** アベイラビリティ、計画/計画外停止日数、熱効率、FTE 等 → **Value Driver** → Capability Monitor

| 燃料費 | 熱効率、運転パターン | 運転計画最適化 | C-A2 |

| 汽力発電費全体 | 収支計画精度 | 収支 PDCA | C-0（Enterprise） |

## 7. KPI 配置（SCN 記法）

### 7.1 数値の3層（有報 vs プログラム定義書）— **混同禁止**

| 層 | 指標 | 数値 | 出典 | SCN 上の位置 |
|----|------|------|------|-------------|
| **A. Baseline Outcome** | 電気事業営業利益（個別） | **124,483 百万円**（≒1,245 億円） | 有報 P.140–142 FY25 | **Value-1 現状アンカー** |
| **A′. Baseline EBITDA** | 営業利益＋D&A | **241,236 百万円**（124,483＋116,753） | 有報 | Value-1 補足（EBITDA 説明用） |
| **B. Program KGI（増分）** | 焚替損失回避 | **86.51 億円/年（2027）**／**109 億円/年（2030）** | JPJ DGD v1.0 §7／プログラム定義書 | **Value Driver 枝への増分効果**（Value-1 と同数値ではない） |
| **B′. Program KGI（増分）** | 運用費削減 | **5 億円/年**＋工数削減（84.1→569 名相当） | 同上 | C-B2 / Enabler 変革 KPI |
| **C. Realized（実績例）** | GDAC 予兆監視効果 | **18 億円（2025 実績）** | DX戦略 Part1 骨子 | C-C2 の実証（KGI 達成の一部） |

**整合の要点:**

- **124,483M ≠ 86.51/109 億** — 前者は**有報ベースライン**、後者は**DX プログラムが創出する年間増分効果（KGI）**。
- 109 億の内訳（DGD v1.0 §8）：保全 **79.5 億**＋運転 **29.3 億**＋資材 SC **0.37 億** → C-B/C-C / C-A2 / 資材 DX に接続。
- プログラム定義書の「目標数値（JPJ 目標に応じ変動）」＝**層 B**。SCN Value-1 には載せず、**Value Driver → Capability 枝**に増分として接続する。
- McK 6/29 の「2–3 年ストレッチ EBITDA」は **A＋B の将来像**（G5）。確定後 Value-1 ストレッチ行を更新。

|--------|--------|----------|-----|
| Value-1 | 発電 EBITDA 最大化 | **Outcome（Baseline）** | 124,483M（個別）＋ D&A 116,753M |
| Value-1′ | プログラム KGI | **Outcome（増分・Forward）** | 焚替回避 86.51/109 億、運用費 5 億 |
| Value Driver | 熱効率・計外 MWh 等 | **Driver KPI** | 燃料費・計外停止の因数分解 |
| Decision | 所長判断 | **Decision KPI** | 計画修正・修繕優先・AI 採否 |
| C-0 | 収支 PDCA | **Monitor** + **Decision** | PDCA 完遂 / 計画修正判断 |
| C-C2 | 計画外停止防止 | **Monitor** | 計画外停止率、バッドアクター数 |
| Enabler | BPR/DX | **変革 KPI**（McK 7/2） | 定着・導入—**単独 EBITDA 責任は置かない** |

**禁止:** DX 登録数・アクティブユーザー数を Outcome にしない（McK メモ p.2）

## 8. 報告テンプレ（長嶋様→森崎様用）

同一 SCN/Value Creation Tree で 1 スライドまたは 4 行：

1. **Value / Value Driver:** どの EBITDA 枝・因数に効くか
2. **Decision:** 所長/本社が下した**判断**（Before/After）
3. **Capability:** Monitor KPI の変化
4. **Enabler:** どの **BPR**／プログラムか—AI 利用率ではなく **判断→行動→KPI** 連鎖
