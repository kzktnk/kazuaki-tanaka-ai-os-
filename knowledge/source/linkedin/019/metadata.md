## Core Theme

Organizational memory becomes practical when we focus on **exceptions**—what happens after the normal case fails. The gap between event and decision is what organizations lose. Intentional deviations by competent people are a better capture target than recording every action.

## Key Distinctions

| Common framing | Reframed insight |
|----------------|------------------|
| Document the normal case | Memory often starts when the normal case stops working |
| Expert "intuition" | Accumulated exposure to exceptions |
| Lost tacit knowledge | Lost **memory of exceptions** |
| Bigger knowledge repository | Memory of how the organization learns from reality |

## Capture questions (operational)

When context still exists after an intentional deviation:

1. What was different this time?
2. Why wasn't the standard response appropriate?
3. What should the next person know?
