## Purpose

クライアントとの会議で、自分の専門を披露する前に次の3つを決める。

1. **役割** — 雇われエキスパートとして入るか、アドバイザーとして入るか。
2. **アジェンダ** — 相手の優先事項か、今の案件の進捗か。
3. **質問** — 考えさせる問いか、閉じた確認か。

この3つは別講座ではない。役割を上げると、アジェンダを取りにいき、そのための質問が要る。

変革で「なぜこの人は動かないか」は `playbooks/stakeholder-activation-playbook.md`。案件の論点は `standards/strategy-engagement-guide.md`。本ファイルは **関係の中での自分の入り方** である。

## When to Use

- 役員・部長との定例が、進捗報告と資料説明で終わっている
- 関係が単発、取引、伸びたあと消える、伸び悩む、のどれかに見える
- 会議の前に、何を話すかは決まっていて、何を聞くかが決まっていない
- 主要クライアントとの関係を、個人の役割と組織的な広がりの両方で見直す

## When Not to Force It

- 相手が狭い専門家を買っている。専門を捨てるシフトではない。その会議では専門で答え、関係の全体をアドバイザーの姿勢で持つ。
- 深い専門家として多数のクライアントを見ており、全員の信頼パートナーにはなれない。なれる会議でアドバイザーの行動を使う。全口座を生涯関係にしない。
- クレームと危機。先に経緯を聞く。弁解と提案を先に置かない。

## 1. 関係の置き場所

個人の役割（雇われエキスパート ↔ クライアントアドバイザー）と、組織関係の幅（狭い ↔ 広い）で置く。

|  | 個人はエキスパート | 個人はアドバイザー |
|--|-------------------|-------------------|
| 組織関係が広い | ベンダー | 信頼できるパートナー |
| 組織関係が狭い | エキスパート | 信頼できるアドバイザー |

広い関係は、多対多と、複数のサービスが同時に動いている状態。肩書がアドバイザーでも、個人が専門の中だけに閉じればベンダー側に残る。

伸びない関係の形は4つ。一度きり。取引の繰り返し。一度は強かったが消える。売上も深さも伸びない。対比は、残って伸びる関係（生涯クライアント）。健全さの結果は、透明性、経済的リターン、紹介、信頼、敬意、価値、継続。これは標語ではなく、会議のあとで関係がどれを積んだかの見方である。

振り返りで見るのは3点。配置を見て何が残ったか。まだ伸びる関係はどれか。見直し、優先を下げる、または終える関係はどれか。企業名の一覧はリポジトリに書かない。

## 2. エキスパートからアドバイザーへ

専門が要らなくなるのではない。専門を見せる姿勢が、関係の上限になる。

| エキスパートの姿勢 | アドバイザーの姿勢 |
|-------------------|-------------------|
| 伝える | 聞き、考えさせる |
| 雇われている | 相手の利益に立つ独立性がある。範囲の外も見、必要なら断る |
| 専門の中に留まる | 専門を持ちつつ全体を統合する |
| 分析する | 分析し、意味にまとめる |
| 信用を積む | 個人としての信頼を積む |
| 頼まれて動く | アジェンダを先に置く |
| 売る | 相手が必要性を自分の言葉にできる状態を作る |

会議で見える行動。

| エキスパート | アドバイザー |
|-------------|-------------|
| スライドに依存する | 会話にする |
| 自分の知っていることを売る | 自組織が知っていることを使う |
| 会う敷居が高い | 会う敷居が低い |
| 依頼に反応する | 全社への波及を探る |
| 関係を軽く見る | 押し返せる。断れる |
| 相手の問題定義を受け取る | 課題の枠を組み直す |
| ベンダーとして入室する | 仲間として入室する |

毎回の会議の前に2問。相手の課題理解を、この会議でどう進めるか。関係をどう深め、相手をどう知るか。

個人の姿勢だけでは伸びない。組織側の条件は、アカウント計画、協働の文化、クライアントの声を聞く仕組み、リーダー育成、ソートリーダーシップ、評価と報酬。個人の心得だけにすると、制度がベンダーのまま残る。

関係を伸ばす原則は3つ。

1. 良い関係は、知識の披露ではなく、良い会話からできる。
2. 成長と利益の側に見えること。費用の側に置かれると切られる。
3. 何か一つで、本当に際立つ。

相手から一つの専門に固定されて見えるときは、その専門の成果を相手の上位目標に接続してから、隣の論点を出す。仕事が断続的なときは、用がなくても接触するのではなく、相手の計画が動くタイミングに合わせる。

## 3. アジェンダは案件の進捗ではない

アジェンダは、相手にとって最も重要な優先・ニーズ・目標の、おおよそ3〜5個。仕事のものと、個人のものとがある。機関のものと、その人のものとがある。

設定は、相手の優先を一緒に形にし、良くする仕事である。相手が感じている課題を聞くだけではない。こちらが重要だと見る課題を、相手が直視する場でもある。

深さは3段。

| 段 | 動き | 話す相手の目安 | 時間軸 |
|----|------|----------------|--------|
| アジェンダ設定 | 目標と戦略 | senior | 計画に近い |
| 感知 | 相手の計画を読み、こちらから仮説を置く | middle も含む | 中間 |
| 反応 | 調達された解決策と進捗 | procurement、実務の窓口 | 実行に近い |

受動から能動へは、反応 → 感知 → 設定、の順でしか上がらない。

非対称がある。こちらが見ているのは案件の優先だけであることが多い。相手の優先の全体は、その外側にある。進捗会議を、相手の優先に接続する場に上げられるか。新しい見方を1つ持ち込めるか。現在と将来の優先について、考えさせる問いがあるか。

よくある壁は、理由ではなく読み間違いであることが多い。相手が戦術的。役職が下。会話が自分の専門の外に出る。相手が計画を話さない。時間がない。壁の名前で、設定を放棄しない。

知る経路は6つ。直接聞く。個人の側を聞く。波及を聞く。事前に調べる。こちらの見方を出す。社内のコーチ（相手を知る同僚）に聞く。調べてから入る。調べた内容を、相手の頭の中だと決めつけて入らない。

個人のアジェンダは、仕事の意味、次に行きたい役割、残したいもの、から入る。私生活の詮索ではない。相手が開いた範囲に留まる。

主要クライアントでは、年に数回、進捗から一段下がる会議を別に置く。依頼の中身は次のとおり。進行中の仕事を大局で見る。変わりつつある計画、優先、こちらの仕事に効く他の決定。こちらの見方、改善のアイデア、同業で見たこと。大規模な関係では、相手側数名、こちら側数名でよい。定例の中でやるなら、進捗の前にこの枠を切る。

設定の手段は、見方とソートリーダーシップ、専用の対話、大きなアイデアの番組、他クライアントとの接続、論点を深く掘る場。手段を増やしても、相手の3〜5個を知らないままだと反応のままである。

会議の前に、相手の事業を次の幅で粗く持つ。戦略と長期目標。主要顧客と、選ばれる理由。来期のオペレーション。主要なサプライヤーと影響力。収益・利益・シェア・競合順位。提携とその効き。組織と主要役員の役割。文化（今の信念と、目指す信念）。競合と業界構造。自分が触っている単位。業界の力学。全部を埋めてから会わない。空白が、質問の場所になる。

## 4. 質問

良い質問の性質は9つ。開いている（はい／いで終わらない）。意外で、相手が考える。限られた時間を、正しい論点に使う。アジェンダを出す（相手は本当のことをすぐには言わない）。原因に届く（症状なら、なぜを繰り返す）。状況の全体を見る。相手に自己採点させる。個人としての理解を深める。もしもの余地を作る。

4象限。合理か感情か、大局か実行か。

|  | 合理 | 感情 |
|--|------|------|
| 大局 | 戦略。目標、文脈、整合 | 志向。野心、情熱、価値観、残したいもの |
| 実行 | 実行。どう、何、いつ | 懸念。苛立ち、不安、リスク |

開発の会話で外さない順序は3つ。相手の野心と目標。それを達成するのに要る能力。今日とのギャップ。この順を、スクリプトとして読み上げない。

質問の仕事は10種。仲間として入る（なぜ今日か、今日の議題の主導、問題定義への押し返し）。ラポール。信頼性（相手の業界と公表情報に合わせる。汎用のまま使わない）。課題の理解。上位目標への接続。特定したニーズの大きさ、波及、放置したコスト。人としての理解。トップとの対話（目標の妥当性、実装の自己評価、現場で見たこと、外部、問題の再定義、組織の効き、選択肢、何が心を動かすか）。次の一歩。危機とクレーム（経緯）。

例文の一覧はリポジトリに置かない。会議の前に、空白の象限と、上の仕事から、自分の文で3問を書く。

使い古されて定型句になった問いは引退させる。コースが名指しする例は、夜眠れないこと、成功の姿、驚いたこと、まだ聞いていない質問は何か。新しさは、相手の公表情報か、直前の発言から作る。

言いたかった主張は、質問に変える。

聞き方。肩の力を抜く。詰めない。質問が多すぎると相手は疲れる。初対面では、少しの文脈と見方のあとで問う。質問の山で入室しない。

## 5. 会議の前とあと

前に1枚。

- この会議の役割（エキスパート／アドバイザー）。仲間として入るか。
- 相手の3〜5個のうち、知っているものと、案件の進捗と取り違えているもの。
- 3問。少なくとも2象限。各問が上の10種のどれか。

あとで対照する。スライドに寄ったか。伝えすぎたか。問題定義を受け取っただけか。敷居を上げたか。付加と、背景の追求と、枠の組み直しがあったか。

質問の暗記と、口座名の一覧は、この1枚の代わりにしない。

- 教材は2021–2022年のマスタークラス。質問集の著作権は Andrew Sobel にあり、本ファイルは判断の骨格だけを持つ。

- アジェンダ設定は、相手の計画を作り替える権限ではない。相手が直視する場を一緒に作る仕事である。
