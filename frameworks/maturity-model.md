# Maturity Model Framework

**Version:** v1.0  
**Status:** Active  
**Owner:** Kazuaki Tanaka  

---

## Purpose

Assess **organizational and process maturity** for transformation and operating improvement using a generic five-level scale.

For **AI-specific role maturity** (users, governors, developers, etc.), use `frameworks/ai-role-maturity.md` instead. This file stays domain-neutral.

---

## Levels

| Level | Name | Characteristics |
|-------|------|-----------------|
| 1 | Initial | Ad hoc; hero-dependent |
| 2 | Repeatable | Basic practices; inconsistent scale |
| 3 | Defined | Documented standards; shared language |
| 4 | Managed | Measured; controlled change |
| 5 | Optimized | Continuous improvement; adaptive |

Same numeric labels as `frameworks/capability-model.md` — align assessments when both are used.
