# スキル別 参照Playbook 早見表

伸ばしたいスキルが決まったら、まずこの表で読むものを探してください。Level判定や評価の話は抜きにして、「何を読めば、何ができるようになるか」だけをまとめています。

一人で読むときは、表の「本編」の代わりに対応する自己学習版（`*-selfstudy.md`）を使ってよい。本編と同じ型である。

---

## Thinking / Problem Solving（考える力）

| スキル | 読むもの | 自走できてくると、こんな感じ |
|---|---|---|
| 問いを立てる | `playbooks/strategy-scn.md` Ch2.1 | 「結局何を明らかにしたいのか」を1文で言える |
| 構造化する | `frameworks/top-down-thinking.md`、`frameworks/thinking-patterns/` | 型（Pattern）を自分で選んで、箱を作れる |
| 仮説を作る | `core/author-voice.md` §1.1、`strategy-scn.md` Ch3 | 事実の羅列で終わらず、「だからこうではないか」まで言える |
| 分析する | `strategy-scn.md` Ch2.3・Ch3.4 | ツールから入らず、「何を出すか」を先に決めてから調べられる |
| 評価・意思決定する | `strategy-scn.md` Ch6 | 都合の悪い制約も隠さずに、選択肢を比べられる |

## Delivery / Execution（実行を回す力）

②（複数PJ統合管理）や③（運用移行）のフェーズで必要になります。Strategy Consultantとして①フェーズを主に担当する人は、今すぐ全部読む必要はありません。

| スキル | 読むもの | 自走できてくると、こんな感じ |
|---|---|---|
| Work Planning／WBS | `playbooks/wbs-design.md`（自習版あり） | 成果物から逆算して、タスクに分解できる |
| Dependency Management | `playbooks/cross-project-program-management.md` Ch3（自習版あり） | PJ間の受け渡しで、何が重要かを見極められる |
| Schedule Integration | 同上 Ch4 | 日付が揃っているだけでなく、前提が噛み合っているか確認できる |
| Scope／Responsibility | 同上 Ch5 | 「どっちの仕事か」があいまいなところを見つけて埋められる |
| Risk／Issue Management | 同上 Ch8 | 感覚でなく数字で、赤黄緑を判定できる |
| Transition Due Diligence／Planning | `playbooks/operations-transition-playbook.md` Ch2・Ch3（自習版あり） | 移行してよいか・まだ危ないかを判断できる |
| Knowledge Transfer | 同上 Ch2.5・Ch3.5 | 「当たり前すぎて言わなかったこと」を引き出せる |
| Transition工数見積もり | 同上 Ch4 | 前提を書き残した見積もりを作れる |

## Stakeholder / Leadership（人を動かす力）

| スキル | 読むもの | 自走できてくると、こんな感じ |
|---|---|---|
| Stakeholder Diagnosis | `playbooks/stakeholder-activation-playbook.md` Ch2・Ch3（自習版あり） | 「なぜこの人は動かないのか」を、思い込みでなく本人確認まで含めて言える |
| Communication | `core/author-voice.md` §3〜4 | 相手（役員／PO等）に合わせて、伝え方を変えられる |
| Facilitation | `standards/scn-creation-guide.md` | 議論が広がりすぎたとき、引き戻せる |
| Influence／Activation | `playbooks/stakeholder-activation-playbook.md` Ch4〜8 | 打ち手を届けて終わりでなく、実際に行動が変わったか確認できる |
| Governance／Escalation | `playbooks/cross-project-program-management.md` Ch8.5、`playbooks/program-governance-cadence.md` | 何でも上に持っていかず、上げる基準を先に決められる |

## Business / Management Literacy（事業を理解する力）

まだ全部は揃っていません。読むものができたスキルから、この表に追加していきます。

| スキル | 読むもの | 自走できてくると、こんな感じ |
|---|---|---|
| Company／Financial Analysis | `frameworks/financial-analysis-for-consultants.md` | 決算資料を自分で読んで、経営課題の仮説を立てられる |
| Business Model／Economics | まだありません | どこで儲けているかを説明でき、SCNに正しく反映できる |
| Investment／Business Case | まだありません | 投資判断の理屈（NPV等）とKPIを混同せずに使い分けられる |
| Corporate Governance／Management | まだありません | このクライアントで本当に決めるのは誰かを見抜ける |
| Commercial／Contract Literacy | まだありません | 契約の危ないポイントに気づき、Legalへの質問に変換できる（法的判断はしない） |
| Regulatory／Risk Literacy | まだありません | 規制がらみの論点に気づき、専門家に確認すべきことを整理できる（法解釈はしない） |
