# New Venture Three-Track Assessment

**Version:** v0.1  
**Status:** Active  
**Owner:** Kazuaki Tanaka  
**Purpose:** 新規デバイス／新規事業の「やりたい」を、**市場シナリオ・技術制約・自社で事業化できるか**の三線で同時に検証する。

## When to use

- 新製品コンセプトの事業性を経営に上げる  
- 技術アセスメントと市場調査が別資料のまま合流していない  
- 先行他社の座組みだけ見て「自社もいける」になりかけている  

## Inputs

- 価値提案（誰のどの不便を、どの機能・性能で解くか）の仮説  
- 技術要素の制約（実現可能性、供給、規制クラスの当たり）  
- 自社の製造・販売・承認・協業の現実  
機密の製品仕様、消費電力、インタビュー対象者名、他社内部は原本のみ。リポジトリに書かない。

## Three tracks (run in parallel)

| Track | Question | Failure if skipped |
|-------|----------|-------------------|
| **Market / scenario** | 広く浸透するか、特定用途に留まるか。代替品と規制が規模をどう変えるか | 単一の TAM スライドで投資判断する |
| **Technology** | 価値提案を支える要素の制約とリスクが列挙されているか | 「原理的に可能」と「量産・承認可能」を混ぜる |
| **Firm fit** | この会社の製造・販路・協業・規制対応で事業化できるか | 先行他社の開発座組みを自社計画にコピーする |

三線は同じ結論を強制しない。市場があっても技術が閉じない、技術が閉じてもこの会社では売れない、があり得る。取りまとめは **矛盾を消さず残す**。

## Outputs

- 機能・性能と技術方針（仮説でよいが、未決を隠さない）  
- 自社・協業を含む技術リスク  
- 市場のシナリオ分岐（単一予測にしない）  
- 「事業化できるか」への条件付き答え  

## Limitations

- 詳細な規制申請、素子設計、財務モデルの確定値は対象外  
- 他社開発責任者へのヒアリング内容は一般化せず原本に留める  

## Risks

- 技術資料の厚みで事業性を代替する  
- シナリオを「楽観／悲観」の二枚に単純化する  
- 経営報告だけが物語になり、三線の証拠が付かない  

## Examples (anonymized)

製造業の新規デバイスで、市場シナリオ・要素技術・自社事業化を別成果物にし、取りまとめで矛盾を残したまま判断する。
