# Capability Model Framework

Version: v0.9 Bootstrap

## Purpose
Describe *what* an organization must be able to do.

## Capability Layers
- Strategic
- Management
- Operational
- Supporting

## Maturity
1. Initial
2. Repeatable
3. Defined
4. Managed
5. Optimized

## Assessment Dimensions
- Process
- People
- Technology
- Data
- Governance

## Related: SCN

For **causal mapping** of value, capabilities, and enablers (KOPT), use
`frameworks/strategic-capability-network.md` and `standards/scn-creation-guide.md`.
This capability model describes layers and maturity; SCN connects them to
strategic outcomes and initiatives in a network.
